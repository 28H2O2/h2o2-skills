# H2O2 Research HTML Skill

安装：把 `h2o2-research-html` 目录复制到 Agent 的 skills 目录，确保 `SKILL.md` 在目录根部。

- `SKILL.md`：生成规则与事实边界
- `references/design-guidelines.md`：视觉与交互规范
- `assets/example.html`：单文件、可交互、离线的视觉参考，使用虚构演示数据
- `assets/example.png`：桌面视觉截图
- `assets/example-mobile.png`：移动端截图

示例使用方式：

> 请使用 h2o2-research-html Skill，根据这些 Agent 运行日志生成单文件 HTML 报告。Trajectory 为主、Scene Map 为辅；Thinking 展示摘要与忠实双语原文；尽量少写解释性段落。

示例不使用网络资源。底部 `✳ crafted by h2o2` 签名可自由移除。
