# 场景报告的视觉起点

白色或浅暖纸底均可，重点是中文可读、对象容易识别。系统字体、少量细线与留白即可；不把旧模板的底色、卡片比例或组件位置当作必须复刻的设计。

可参考蓝 `#2e65c8` 表示 Agent／任务，青绿 `#148775` 表示正常资源，橙 `#ba711b` 表示投毒载体，红 `#c14a48` 表示破坏风险，紫 `#7653b6` 表示评估者／证据。按场景选需要的类别，不必凑齐所有颜色；同页保持语义一致，使用浅色底配清晰文字。

颜色表示类别或风险，选中用轮廓／边框，配置、使用、未知和执行结果用文字或标记。红色投毒／风险区域不代表攻击已成功；未使用工具也不能染成失败状态。不要同时用一种颜色混指类别、是否调用和成功率。

Instruction 中文明显大于辅助信息，关键资源用途名不能缩成小标签；具体字号见 `typography.md`。原文、长清单与代码按需展开，桌面先保证场景可见，再适配手机。

`assets/signature.html` 提供可选的低调 `crafted by h2o2` 落款；它不是实验作者或翻译审核声明。样式与资源独立附带，不需要共享包、远程字体或另一个 Skill。`assets/report-template.html` 当前仍为 V1.4 兼容布局。
